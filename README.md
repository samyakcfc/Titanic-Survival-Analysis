# Titanic Survival Analysis

## Objective
A junior data analyst project analyzing Titanic passenger data to uncover survival patterns through data cleaning, feature engineering, and exploratory data analysis.

## Dataset Information
891 passenger records with demographic info (age, sex), ticket details (class, fare, cabin), family relationships aboard, and survival outcome. Source: Kaggle Titanic dataset.

## Folder Structure
Titanic-Survival-Analysis/
├── data/ (titanic.csv, clean_titanic.csv)
├── notebook/ (Assignment2.ipynb)
├── report/ (Titanic_Report.pdf)
├── images/ (chart screenshots)
├── README.md
└── requirements.txt


## Libraries Used
- pandas
- numpy
- matplotlib
- seaborn

## Installation Instructions

pip install -r requirements.txt


## How to Run
1. Ensure `titanic.csv` is inside the `data/` folder.
2. Open `notebook/Assignment2.ipynb` in VS Code or Jupyter.
3. Run all cells from top to bottom.

## Key Findings
- Female passengers survived at 74.2% vs 18.9% for males.
- First-class passengers survived at 63.0% vs 24.2% for third-class.
- Higher fares strongly associated with better survival odds.
- Passengers with small family sizes (2-4) had better survival odds than solo travelers or large families.
